## 📋 Descripción del Proyecto

**UrbanStride** es un sitio web responsivo y multimedial desarrollado para la evaluación parcial de Diseño Web de la Universidad de Ciencias y Humanidades (UCH). La plataforma incluye un catálogo interactivo de zapatillas, integración de reproductores multimedia (audio local promocional y video incrustado desde YouTube) y accesos directos a redes sociales como TikTok, Facebook, Instagram y WhatsApp.

---

## 🚀 Tecnologías Utilizadas

- **HTML5:** Estructura semántica (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) e integración multimedia.
- **CSS3:** Hoja de estilos externa (`css/style.css`), diseño adaptativo (*Media Queries*), variables CSS, animaciones interactivas (`@keyframes`, `transition` y `transform`).
- **Font Awesome (v6.5.1):** Íconos vectoriales para la interacción con redes sociales.
- **GitHub & GitHub Pages:** Control de versiones y publicación en la nube.
